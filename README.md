# month-day-checker
This Python program determines the number of days in any month of a given year.
It accurately accounts for leap years, so February is correctly calculated as either 28 or 29 days depending on the year

Why the Project is useful:
- Helps beginners practice Python functions, dictionaries, and conditional logic.
- Demonstrates how to handle real-world calendar calculations.
- Useful for anyone learning Python or building small command-line tools.
